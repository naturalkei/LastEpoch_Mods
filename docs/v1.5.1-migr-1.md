## 맞춘 API

- `AffixList`, `ItemList`, `CharacterClassList`, `QuestList`, `ShrineList`는 `.instance` 대신 `get()`을 쓴다.
- `MapPanel`, `InventoryPanelUI`는 `FindObjectOfType`으로 찾는다.
- 신전 설치는 `ShrinesManager.PlaceNewShrine(int, Vector3)`이다. `ShrinePlacementManager`는 이 빌드에 없다.
- `ActorData`는 `ActorSoftRef`, `VisualsSoftRef`를 쓴다.
- `ItemData.ApplyCorruptionOutcome`은 `forPrecorruptedItem=false`, `level=0`을 포함한 7인자 호출이다.
- 모노리스 `waveSpawner.spawnsRemaining[0]`은 `Actor`다. `gameObject`로 위치와 `Dying`을 다룬다.
- `Il2CppLE.Addressables` 참조를 추가했다.
- 아이템 아이콘은 `ItemData.GetItemSpriteFromData`가 돌려주는 `SoftRef<Sprite>`를 `CreateLoadRef`로 열고, 이미 로드된 경우만 `AssetOrNull`을 쓴다.
- `UITooltipItem.GetItemSprite`의 Harmony postfix는 제거했다. 반환 타입이 `SoftRef<Sprite>`라 라이브 `Sprite`를 넣을 수 없고, 예전 `ref Sprite __result`는 패치 적용 때 실패한다.
