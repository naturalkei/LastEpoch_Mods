## 14:02 실행

실행 파일은 `Last Epoch.exe --offline`이다. 로드된 모드 해시는 `CAC583347105492C7011950448CF77DCB4F4CFE06A4EBA1B8D9CC2B20BB41365`로 migr-4 DLL이다.

스플래시 멈춤은 넘어갔다. `Player.log`는 `SplashScreen -> Login`과 `Application state changed to Login`까지 간다. 사용자는 로딩 중 Esc로 로그인 창을 봤고, 캐릭터 선택으로는 넘어가지 않은 뒤 종료했다.

캐릭터 선택을 막은 예외:

`InvalidOperationException: Cannot transition to CharacterSelect while transition to SystemLoading is in progress`

스택은 `LandingZonePanel.AdvancePlayerToCharacterSelect`다. 시각은 05:03:19 UTC이고, 셸이 Login이 된 시각은 05:03:22 UTC다. `Save.json`의 `Enable_AutoLoginOffline`이 true라 로그인 패널 `OnEnable`에서 바로 `OnPlayOfflineClicked()`가 호출됐다. 그 시점에는 SystemLoading 전환이 아직 끝나지 않았다.

같이 보인 로그 중 이번 멈춤의 원인이 아닌 것:

- `Curl error 42`와 `Error loading character list: A task was canceled`. `--offline`이라 온라인 캐릭터 목록 요청이 취소되고, 게임은 오프라인 캐릭터만 쓴다고 경고한다.
- `Actor is null`. 로그인과 캐릭터 선택 씬을 로드할 때 `PlayerSpawnManager.PlacePlayer`가 찍는다.
- Harmony 대상이 없는 패치 세 개. 미니맵 `OnInitializeFoW`, `GroundItemVisuals.initialise`, `rollLegendaryPotential`.
- `ko.json` 없음, `TimeBeastData not found`.

## 맞춘 것

- 오프라인 자동 로그인은 `ClientStateManager.CurrentClientAppStateType`이 `Login`이 된 뒤에 `OnPlayOfflineClicked()`를 호출한다. 그 전에는 패널만 기억하고 `OnLateUpdate`에서 다시 본다.
